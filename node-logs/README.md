# Node logs (append-only)

Each multi-model session that changes architecture or code should add a dated file:

```
node-logs/YYYY-MM-DD_<model-or-session>_vector.md
```

Contents = one or more **AI NODE COMMIT LOG** blocks.

Do not rewrite history; append new files.

Index of sessions starts with `node-logs/2026-08-11_grok_protocol-init.md`.
